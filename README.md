# 学習ナビ

サーバーコスト・データベース不要、ブラウザだけで動く学習支援アプリです。HTML / CSS / JavaScript のみで作られた静的サイトなので、GitHub Pages で無料公開できます。データはすべて各ユーザーのブラウザの `localStorage` に保存され、外部サーバーへの送信は一切行いません。

## 主な機能

- **教材（教材整理）**: 教科ごとに解説をセクション単位で管理。Claude などで作成した解説テキストを貼り付け／ファイルアップロード（.txt / .md / **PDF**）すると、Markdown の見出し（`#`）で自動的にセクション分割され、各セクションをどの教科に振り分けるか（Allocate）を1件ずつ選べます。PDFは文字が選択できるものに対応しており、ページ単位で自動的にセクション分割されます（スキャン画像のみのPDFは非対応）。PDF解析はブラウザ内で完結し、[pdf.js](https://mozilla.github.io/pdf.js/) ライブラリをCDNから読み込むときだけインターネット接続が必要です（サーバー処理・費用は発生しません）。
- **Todo**: タイトル・タグ・所要時間（分）を記録し、タグで絞り込み、完了状況や合計見積もり時間を確認できます。日付と開始時刻を入力すると、所要時間から終了時刻が自動計算され、カレンダーに反映されます。
- **カレンダー**: Todoに設定した日付を月表示のカレンダーで確認できます。日付をクリックすると、その日の予定を時間軸（タイムライン）でビジュアル化して表示し、各タスクの開始〜終了時刻・時間が重なる予定の並列表示・時間未設定タスクの一覧・その日の合計作業時間（分単位／時間換算）をまとめて確認できます。タイムラインの予定やTodo一覧の行をクリックすると編集モーダルが開き、タイトル・タグ・所要時間・日付・開始時刻の変更や削除がその場でできます。
- **クイズ**: 教科とセクションの範囲を選んで出題。取り込んだ解説文中の `用語：説明` 形式の行を自動解析し、四択クイズを生成します。該当行が少ない場合は本文の文章から「この説明はどのセクションの内容か」を問う問題を補って出題します。すべて自動生成・自動採点で、外部AI呼び出しは行いません。
- **YouTube Player**: ヘッダーの「📺 動画」ボタンから、どの画面にいても開けるフローティングプレーヤーを表示できます。動画のURL（通常のリンク・短縮URL・Shorts・埋め込みURLに対応）または動画IDを貼り付けて再生でき、作業しながら講義動画やBGMを流すといった使い方ができます。埋め込みは [youtube-nocookie.com](https://support.google.com/youtube/answer/171780) を使い、APIキーやサーバーは不要です。プレーヤー左上の角をドラッグするとサイズを自由に変更でき（ダブルクリックで既定サイズに戻ります）、サイズは次回開いたときも記憶されます。
- **プレイリスト**: 複数のYouTube動画を2列の大きめのグリッドに、画面幅いっぱいに並べて表示し、タブを開くとそれぞれ自動再生（ミュート状態、ブラウザの自動再生ポリシーのため）されます。URLを追加すればグリッドに増え、各動画にカーソルを合わせると表示される✕ボタンで削除できます。
- **PDFフォルダ**: フォルダを自由に作成し、その中にPDFファイルをアップロードして整理できます。PDFの実ファイルはブラウザの IndexedDB に保存されるため、後から「開く」でそのまま閲覧・「内容を読む」でテキスト抽出結果を確認できます（テキスト抽出には教材タブと同じく pdf.js の読み込みが必要です）。フォルダ・PDFともに「名前を変更」で改名でき、ドラッグ＆ドロップでフォルダの中に移動できます（パンくずリストにドロップすると上の階層に移動）。フォルダはネストでき、削除するとその中のPDF・サブフォルダもまとめて削除されます。
- **経済学**: 左サイドバーで教科・ユニットを選ぶ専用タブです。現在は「経済学」→「Unit 2: マイクロ経済」を実装しており、IBDP Economics SL相当の用語集（24語）と、実際にドラッグして動かせるインタラクティブなグラフを掲載しています。
  - ① 需要・供給曲線のシフト（D・Sをドラッグして均衡価格・数量の変化を確認）
  - ② 価格の上限規制・下限規制（規制価格の線をドラッグすると、不足・余剰の発生が自動的に切り替わります）
  - ③ 間接税・補助金（供給曲線を上下にドラッグして税・補助金の負担配分を確認）
  - ④ 外部性（負の生産の外部性／正の消費の外部性を切り替え、外部性の大きさをドラッグで調整し、死荷重の変化を確認）
  
  どのグラフも操作結果に応じて下の説明文が自動的に切り替わります。Unit 3・4は今後追加予定です。すべて素のSVG＋JavaScriptで実装しており、外部ライブラリやサーバーは使用していません。

## フラッシュ単語（flashword.html）

フラッシュ暗算の数字の代わりに、単語をパッパッと1つずつ表示するツールです。`flashword.html` を開き、左側の欄に文章を貼り付けてスタートを押すと、スペース（半角・全角・改行）で区切られた単語が画面中央に次々と表示されます。

- スピードはバーで調整できます（1語あたり約2秒〜0.06秒）。再生中でも変更できます。
- 文字サイズ、単語間のブランク、開始前のカウントダウン、シャッフル、繰り返しを切り替えられます。
- ショートカット: Space = スタート／一時停止、Esc = 停止、← → = スピード調整。
- 貼り付けた文章と設定はブラウザの `localStorage` に保存されます。

## 単語クエスト（wordquest.html）

ゲーム感覚で覚えるフラッシュカード式の単語テスト帳です。`wordquest.html` を開いて使います。データはブラウザの `localStorage` に保存されます。

- **インポート**: `単語,意味` または `単語,意味,タグ` 形式のCSVを貼り付け（またはファイル読み込み）。カンマ・タブ（Excel/スプレッドシートからのコピペ）・`：` 区切りに対応。3列目のタグは `;` `|` スペースで複数指定でき、「まとめて付けるタグ」で全行に同じタグを付けられます。既存の単語は意味を上書き・タグを追加します。
- **プレイ**: タグ（カテゴリー）を選んで常に4択で出題。「単語→意味／意味→単語／ミックス」、問題数、出題モード（おまかせ＝苦手・未回答が出やすい／苦手のみ／未回答のみ）を選べます。キーボード 1〜4 で回答、Enter で次へ。
- **XP・レベル**: 回答するとXP獲得（正解10＋スピードボーナス＋コンボボーナス、不正解でも2）。プレイヤーはLv1から始まり、レベルが上がるほど次に必要なXPが増えます。各単語も「回答数＋正答数×2」でレベルが上がります。
- **単語一覧**: 全単語をアルファベット順に見出し付きで表示し、各単語の「回答数・正答率・レベル・平均回答時間」を確認できます。検索、タグ絞り込み、一括タグ付け／削除、タグの名前変更・削除、単語の編集ができます。
- **カレンダー**: 日ごとのインポート数・回答数・正答数・正答率・学習時間・獲得XP、その日に回答した単語／追加した単語を記録します。連続学習日数も表示します。
- **プロフィール**: 合計回答数、平均正答率、合計学習時間（各カードの回答にかかった時間の合計）、1問あたりの平均時間、直近14日のグラフ、単語レベル分布など。JSONでのバックアップ／復元にも対応しています。

## 解説ファイルの書き方（推奨フォーマット）

```
# 第1章 力のつり合い
- 力：物体の運動状態を変化させる作用
- 慣性：外力が働かない限り運動状態を維持する性質
物体に働く力の合計がゼロのとき、物体は静止または等速直線運動を続ける。

# 第2章 エネルギー
- 運動エネルギー：物体が運動していることにより持つエネルギー
本文の説明...
```

- `#`〜`######` の見出し行でセクションが分割されます。
- 行頭が `用語：説明` または `- 用語：説明` の形式だと、その行がクイズの問題として自動的に使われます。
- Claude など任意のAIチャットで「〇〇について解説文を作って。用語は `用語：説明` の形式で書いて」と頼み、出力をコピーしてこのアプリに貼り付ける、という使い方を想定しています（AI呼び出し自体はこのアプリの外で行うため、サーバーコストは発生しません）。

## ローカルでの確認方法

ビルド不要です。リポジトリ直下で簡易サーバーを立てて `index.html` を開くだけで動作します。

```bash
python3 -m http.server 8080
# http://localhost:8080/ をブラウザで開く
```

## GitHub Pages での公開方法（無料）

1. GitHub のリポジトリページで **Settings → Pages** を開く
2. **Source** を `Deploy from a branch` にする
3. **Branch** をこのアプリを配置したブランチ（例: `main`）、フォルダを `/ (root)` に設定して **Save**
4. しばらくすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

以降はこのリポジトリに push するだけで自動的にサイトが更新されます。サーバー管理やホスティング費用は発生しません。

## データについて

- すべてのデータ（教材・Todo・クイズ用語）はブラウザの `localStorage` に保存されます。
- 端末やブラウザを変えるとデータは引き継がれません。他の端末でも使いたい場合は、今後の拡張として「エクスポート/インポート（JSONファイル）」機能の追加を検討してください。
