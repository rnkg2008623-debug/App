# Velocity & Jump Mod（マイクラ 26.3 / Fabric）

空を飛んだり、空中を歩いたり、ジャンプの高さや速さを変えたりできる Mod です。
**O キー**を押すと設定メニューが開き、スライドバーで調整できます。

- マイクラのバージョン: **26.3**
- 必要なもの: **Fabric**、**Fabric API**

## 入れ方

1. [Fabric Installer](https://fabricmc.net/use/installer/) で、マイクラ 26.3 に Fabric を入れる
2. [Fabric API](https://modrinth.com/mod/fabric-api) をダウンロードする
3. GitHub の **Actions → velocity-jump-mod** を開き、一番新しい実行結果の「Artifacts」からこの Mod をダウンロードする（zip を解凍すると jar が出てきます）
4. 2 と 3 の jar を `.minecraft/mods` フォルダに入れる
5. ランチャーで Fabric を選んで起動する

## キー

| キー | 動き |
| --- | --- |
| **O** | 設定メニューを開く |
| **V** | 見ている方向にダッシュ |
| **G** | 真上に飛び上がる |

キーは「設定 → 操作設定 → Velocity & Jump」で変えられます。

## 設定メニュー（O キー）

| 項目 | 説明 |
| --- | --- |
| 飛行 ON/OFF | ON にすると、**スペースキーを 2 回押す**と空を飛べます（クリエイティブと同じ操作）。飛んでいる間は、スペースで上昇、Shift で下降 |
| 飛行速度 | 飛ぶ速さ（×1.0 がクリエイティブと同じ速さ） |
| 空中歩行 ON/OFF | ON にすると、空中に見えない床があるように**歩いたり走ったり**できます。ジャンプするとその高さに床ができるので、ジャンプを繰り返すと上に登れます。**Shift を押している間は下に降ります** |
| ジャンプ高さ変更 ON/OFF | ON にすると、下のスライドバーの高さまでジャンプできます |
| ジャンプの高さ | 何ブロックの高さまで跳ぶか（普通のジャンプは約 1.25 ブロック） |
| ダッシュの強さ | V キーで進む強さ |
| 打ち上げの強さ | G キーで飛び上がる強さ |

設定は自動で保存されます（`config/velocityjump.properties`）。

## 注意

- **シングルプレイ用**です。飛行か空中歩行が ON の間は、落下ダメージも受けません。
- サーバーで使うと、キックされたりチート扱いされたりすることがあります。
- 飛行と空中歩行が両方 OFF のときに高くジャンプすると、落下ダメージを受けます。

## 自分でビルドする場合（上級者向け）

JDK 25 が必要です。

```sh
cd minecraft-mod/velocity-jump-mod
./gradlew build
# → build/libs/velocity-jump-mod-1.2.0.jar
```
