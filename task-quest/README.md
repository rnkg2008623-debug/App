# TaskQuest

タスク管理と放置ゲーム要素を組み合わせた、MacBook用の完全無料デスクトップアプリです。Electron製で、サーバー・課金・Apple Developer登録は一切不要です。すべてのデータはお使いのMac内（アプリのユーザーデータフォルダ）にのみ保存されます。

## 主な機能

1. **Todo** — タイトル・説明・所要時間を記録し、編集／削除／完了チェックができます。
2. **Timetable** — 曜日ごとに仕事や授業などの予定を自分で入力できます。
3. **統計** — 作業を完了した回数と、累計作業時間を秒／分／時間／日／月／年に自動換算して表示します。
4. **作業タイマー**（画面上部の常設バー） — 「作業開始」を押して時間を入力するとタイマーが始まります。タイマーはアプリ本体のプロセス（メインプロセス）で動くため、別のタブ／別のウィンドウに切り替えても止まりません。Macがスリープ（画面を閉じる等）した場合は物理的にプログラムが停止しますが、**復帰時・再起動時に経過した実時間から自動的に追いつき計算（キャッチアップ）を行う**ため、スリープ中の分も含めて正しく進捗・報酬が反映されます。
5. **報酬（称号・アイテム・モンスター）** — 作業中は3分ごとに、低確率で称号・アイテム・モンスターのいずれかを入手できるか判定されます（OS通知は出しません。バーの下やコレクション画面で確認できます）。
   - 称号：一度入手すると二度と出現しません（重複なし）。
   - アイテム／モンスター：重複入手可能です。ブースト系アイテムを使うと、一定時間だけ判定間隔を短縮したり、確率を上げたりできます。
6. **バトル（深層探検）** — 1階〜-1000階のダンジョンを完全自動・5秒に1ターンで進みます。パーティが全滅しても階層はリセットされず、全回復して同じ階から再挑戦します。
7. **編成** — 作業報酬で入手したモンスターの中から、バトルに連れていく3体を選びます。モンスターは入手時にランダムな個体値（H/A/D/S）を持ちます。
8. **強化** — 同じ種族の重複モンスターや強化アイテムをモンスターに合成し、経験値を加算してレベルアップさせます。

## 開発・動作確認（ローカル）

```bash
cd task-quest
npm install
npm start
```

## macOS用アプリとしてパッケージする（無料）

Apple Developer Program（年会費）への登録なしで、無料でビルド・配布できる方法です。署名なし（unsigned）ビルドになります。

```bash
cd task-quest
npm install
npm run dist:mac
```

`release/` フォルダに以下が生成されます。

- `TaskQuest-<version>-mac.zip` … Intel Mac用
- `TaskQuest-<version>-arm64-mac.zip` … Apple Silicon（M1/M2/M3など）用

### Macでの開き方（初回のみ手順が必要です）

このアプリはApple公証（notarization）を受けていない無料ビルドのため、初回起動時にGatekeeperが警告を出します。以下の手順で開いてください（無料の範囲で正規の回避方法です）。

1. zipを展開し、`TaskQuest.app` をアプリケーションフォルダなどに移動
2. `TaskQuest.app` を **右クリック（またはControlキーを押しながらクリック） → 「開く」** を選択
3. 表示された警告ダイアログでもう一度「開く」を選択

これ以降は通常のダブルクリックで起動できます。

## データの保存場所

アプリ内のすべてのデータ（Todo・Timetable・統計・モンスター・アイテムなど）は、Macのユーザーデータフォルダ（`~/Library/Application Support/TaskQuest/config.json`）にJSON形式で保存されます。外部サーバーへの送信は一切行いません。
